# Feature Definitions

## Engineered Features

| Feature | Description |
|---------|-------------|
| purchase_month | Month when the order was placed |
| purchase_day | Day of the week of purchase |
| is_weekend | Indicates whether the purchase was made on a weekend |
| estimated_delivery_days | Number of estimated delivery days |
| freight_to_price_ratio | Freight value divided by product price |
| same_state | Whether customer and seller are in the same state |
| seller_delay_rate | Historical late delivery rate of the seller |
| seller_lat | Seller latitude |
| seller_lng | Seller longitude |
| customer_lat | Customer latitude |
| customer_lng | Customer longitude |
| distance_km | Distance between seller and customer |
| is_late | Target variable (1 = Late, 0 = On Time) |
